# Daltons AI landing page

Static HTML landing page for Daltons AI.

## Run locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Before publishing

- Replace placeholder KvK details and contact information.
- Replace `#` social links with real URLs.
- Add your privacy policy, cookie notice, and terms pages.
- Verify all claims, pricing, and customer statistics.
- Consider self-hosting fonts if you need a fully independent deployment.
